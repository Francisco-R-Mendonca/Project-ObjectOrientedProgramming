# Object-Oriented Programming Project

This project consists of developing an application to manage a veterinary hotel, including animal care, staff management, and habitat maintenance.

The system manages animals of different species, caregivers responsible for feeding and cleaning habitats, and veterinarians responsible for ensuring animal health. It also accounts for the impact of administering vaccines inappropriate for an animal's species and allows the calculation of satisfaction levels for both animals and staff.
